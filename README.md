# NRF-KeMoSw setup page

The Web Bluetooth setup page for the NRF-KeMoSw keyboard and mouse switch (a Seeed XIAO nRF52840 that shares an
MX Keys and MX Master 3 between up to four computers). It is served at https://fducloux.github.io/NRF-KeMoSw/ and is
what the hub's NFC tag opens. The firmware lives in a separate repository.

Use Chrome or Edge, Android Chrome, or the Bluefy browser on iPhone (Safari has no Web Bluetooth).
Open setup on the hub first (power-up, an NFC tap, or Ctrl+Shift then 8 R E C on the MX Keys), then press Connect.
